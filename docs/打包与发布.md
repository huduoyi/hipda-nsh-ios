# HiPDA·nsh 版 0.1.0 — 安装说明

## macOS（已验证）

```
HiPDA-nsh-0.1.0-macos-universal.dmg    43 MB · Apple silicon + Intel
```

1. 双击挂载，把 **HiPDA·nsh 版** 拖到 Applications
2. **首次打开请右键 →「打开」**。安装包是 ad-hoc 签名（没有开发者证书），
   Gatekeeper 会拦一次；也可以先执行：
   ```sh
   xattr -dr com.apple.quarantine "/Applications/HiPDA·nsh 版.app"
   ```
3. 已实测：打包产物在本机启动正常，登录态、缓存、图片、回帖链路均可用

## Windows（已验证，2026-11-18）

```
HiPDA-nsh-0.1.0-windows-x64-setup.exe    20 MB · 单个 exe，免管理员
```

1. 双击运行，一路下一步即可。**不弹 UAC**：装到
   `%LOCALAPPDATA%\Programs\HiPDA-nsh`，快捷方式与卸载项全在 HKCU。
2. 组成：安装器是 NSIS 打包的，内含 LZMA 压缩的
   `HiPDA-nsh.exe`（92 MB，release）+ `icon.ico` + 卸载程序。
3. 已实测：静默安装 → 启动渲染真实论坛首页 → 卸载后目录、注册表项、
   开始菜单项全部清空，无残留（`uninstall.exe /S` 同样可用）。
4. 运行时零依赖：不需要 .NET、不需要 WebView2、不需要 VC++ 运行库
   （GNU target 把 libgcc / libwinpthread 静态链接进 exe）。

### 怎么打

```sh
# 一次搞定：release 构建 + NSIS 编译，产物落 dist/
scripts/package-windows.sh

# 已有 release 产物时跳过构建
SKIP_BUILD=1 scripts/package-windows.sh
```

依赖只有两样，都不需要管理员权限：

| 依赖 | 获取方式 |
|---|---|
| Rust（`x86_64-pc-windows-gnu`）+ mingw 工具链 | 见 `scripts/env-win.sh` 注释 |
| NSIS 3.11 便携包 | `https://master.dl.sourceforge.net/project/nsis/NSIS%203/3.11/nsis-3.11.zip`，解压到 `~/tools/nsis` |

安装脚本是 `installer/hipda-nsh.nsi`（UTF-8 **带 BOM**，否则 makensis 里的中文会乱码）。

### 为什么不走 `nsh package --target windows`

`nsh package` 要 `cargo-xwin` + 完整 LLVM 交叉编译链，产出的还是「exe + bundle 目录」
的便携包；而本机的 Windows 原生构建（GNU target）已经能直接出单文件 exe，
用 NSIS 包一层就是真正的安装包——更少的工具链、更小的分发体积、免提权。

`.github/workflows/release.yml` 那条 CI 路径仍然保留，跨平台发版时仍可复用。
